Bases de données

Ma définition

Les bases de données sont un ensemble structuré de données stocké de maniere persistente, cela permet de conserver des informations importantes lié au bon fonctionnement d'une application.

De nos jours on distingue deux grand modèle de gestion de données : Les bases de données relationnelles SQL et les bases de données non relationnelles dites NoSQL (Not Only SQL). Les bases de données relationnelles SQL reposent sur un système de table interconnectés entre elle avec des schéma strict garantissant l'intégrité des données durant les transactions, de l'autre côté les bases de données non relationnelles NoSQL fonctionnent avec un système bien plus flexible et modulable, les données peuvent être stocker sous forme de JSON, de fichier clé valeur ou de graphe, le NoSQL favorise la scalabilité horizontale de l'architecture.
